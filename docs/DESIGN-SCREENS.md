## 连续路径

- 首页 → 雷达观察 → 解读详情 → 轻对话 → 团队过程/结果 → 返回原解读。
- 项目列表 → 媒体或软件项目 → 成果/资料 → 原工作；新建与导入是项目列表的独立入口。
- 同一工作在轻对话、左右双区和三面自由布局中保留目标、引用及成果版本；团队与流程配置独立于排列。
- 资产列表 → 方法详情 → 选择工作引用；定时列表 → 委托详情 → 原工作结果，新建委托复用同一对象关系。
- 设置四个内容视图共用分组导航，连接、权限、数据和偏好分别解释。
