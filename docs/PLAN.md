# ytriple 当前状态与开发重点

更新：2026-09-19。本阶段只以你本人的实际使用为目标，不为多用户、商业化或远期平台预建功能。

## 目标与整体判断

**你能把正在做的项目、关注的信息和本地材料交给 AI 团队，持续讨论，看到依据与过程，得到可修改、可保存、可复用的成果。** ycore 只提供这条路径需要的稳定信息、模型和账号服务。

当前是一个功能较多的开发版：**团队协作主线的验证最充分；项目理解、媒体项目和资产主动复用还只是部分能力；最新合并版尚未交付。** 不能概括为“所有核心功能已完成，只差安装”。

状态：**已走通**有历史路径证据；**已实现**已接代码，待新版验收；**部分**仅支持较窄操作；**未接通**无法完成。隔离样例和历史通过不等于你已认可当前体验。

## 审查后的开发重点

- [ ] **先用同一合并版完成你的三条真实路径。** ① 关注内容→阅读/问团队→成果；② 现有软件项目→读代码/文档→现状与建议；③ 成果→AI 资产→新工作复用。记录卡点与结果是否有用，不能拼接不同版本的验证。
- [ ] **只修这些路径暴露的缺口。** 优先处理材料实际能否读到、项目分析是否有依据、历史成果是否正确接续、资产能否复用。安装/服务对齐属于交付条件；不自动将“未实现”全表变为待开发清单，不为单人使用补多租户、计费或平台框架。
- [ ] **核心路径通过后再决定后台接续。** 如日常确实需要退出应用继续，先一项服务空间普通工作，再复用既有定时委托。稳定运行、费用保护和备份恢复随实际交付验证，不单独扩成平台。

不开发：更多模型/来源/模板、自动学习、收费、复杂搜索、更多布局、通用同步平台。重复入口优先合并，保留用户数据、基本保存、权限、费用保护和恢复。
