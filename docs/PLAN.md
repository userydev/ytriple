## 分工与冻结范围

| 归属 | 本阶段责任 |
| --- | --- |
| ycore | 稳定公共 API、身份与产品权益、共享信息采集/来源/修订/增量、模型适配、持久 AI 任务与授权、用量与服务运行保障 |
| ytriple | 消费 API 与账号会话、材料落盘与引用、执行状态展示；复用现有团队内核补齐必要的私有服务控制、获准上下文和成果接续 |
| 保持本地 | AI/Code 根目录、原项目文件、未获准上传的材料与凭据；服务器不能读取本机路径时明确说明 |

ycore 优先不等于把团队编排、雷达判断、项目资料和私有成果搬进公共信息库。服务部署位置与代码归属分开；复用既有 VPS 和托管数据库，不新增平行网关或通用平台。两仓库通过版本化 API 配合，不直接读写对方业务表。

本轮按用户要求扩大默认团队、聊天办理雷达/定时对象和持续来源供给；其余首页、项目、资产与工作面范围保持不变。不整套重画 UI，不加手动成果编辑器、移动端、付费套餐、更多模型、通用 MCP/插件平台、复杂知识图谱或批量连接器。团队搭配和流程保持独立版本。
