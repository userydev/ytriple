## 按需模板

- [MODULE.md](../templates/MODULE.md)：复杂模块才建立 `docs/modules/<name>.md`。
- [WORK.md](../templates/WORK.md)：复杂、跨模块或高风险任务才建立 `docs/plans/active/<id>.md`。
- [UX.md](../templates/UX.md)：主要交互需要独立说明时才建立 `docs/UX.md`。

不创建空模块凑目录，不把模板中的例子或占位标识当作需求。小任务直接记入版本计划；完成的活动计划移入 `docs/plans/completed/` 并更新引用，不保留两个现行副本。

## 读取与证据规则

开始或恢复：索引 → 当前版本 → 相关活动计划 → 涉及的需求、模块、代码与测试。
修改模块边界或共享接口时补读架构与受影响调用方；不每轮全文读取，不默认读取历史。
文档中的目标与当前运行证据分开；通过记录对应实际命令/场景、环境、时间和提交或工作树。
证据只保留必要脱敏记录，长日志不在多处重复。
