# ytriple

ytriple 面向个人开发者和自媒体创作者，以可调整角色和能力的 AI 团队为默认工作方式，帮助用户消化资料、形成成果，并从可见的工作过程与修正中学会方法。

计划中的主要体验包括：

- 在主窗口讨论目标，在思维窗口学习处理流程、定位不足，在结果窗口阅读和修订成果。
- 与团队把新产品聊透，初始化标准开发项目供 Codex 等专业工具接手；全面理解已有项目、管理状态并写入固定建议文档。
- 围绕媒体作品持续工作，复用资料、Skills 和逐步完善的方法。
- 通过雷达消化信息，通过定时任务管理已委托的例行工作。

产品采用本地优先方向，保留官方服务、自部署和自带 API 的选择。

当前仓库处于产品定义与方案讨论阶段，尚无可运行客户端、服务器或安装包；上述能力尚未实现。可阅读[完整产品定义](docs/PRODUCT.md)了解预期行为。
