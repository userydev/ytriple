# ytriple

> **当前状态：失败快照，P1 未完成。** 当前桌面布局、功能呈现和完整使用流程未通过验收，保留源码供追溯，不作为可用版本发布。

ytriple 是面向个人开发者和创作者的 AI 团队工作台。围绕同一项工作，交流明确方向，公开过程呈现分工、依据和核查，成果窗口保留可继续修订的 Markdown 正文。

当前快照为 **0.1.1 / 未通过验收的 P1 开发稿**：独立服务与桌面客户端，默认多 Agent 团队，以及可选的桌面本地模式。Gemini 是主要模型接入，另支持用户自行配置的 OpenAI Chat Completions 兼容提供方。模型密钥在执行端配置，服务模式下客户端只保存服务访问令牌。

## 启动服务

需要 Node.js 24.20 或更新版本、npm。首次安装：

```sh
npm ci
```

在运行服务的终端或部署环境配置 `GEMINI_API_KEY`（也支持 `GOOGLE_API_KEY`），随后启动：

```sh
npm run server
```

默认地址 `http://127.0.0.1:4317`，数据保存在 `.ytriple-server/`。首次运行生成仅当前用户可读的 `.ytriple-server/access-token`，将其内容填入客户端的“服务访问令牌”；令牌不会出现在服务日志中。也可以通过 `YTRIPLE_SERVER_TOKEN` 提供至少 24 字符的随机令牌。勿提交凭据或令牌。

| 环境变量 | 用途 |
| --- | --- |
| `YTRIPLE_DATA_DIR` | 服务工作空间目录，需持久化保留 |
| `YTRIPLE_HOST` / `PORT` | 默认 `127.0.0.1` / `4317`；其他设备的局域网开发可显式监听 `0.0.0.0` |
| `YTRIPLE_PROVIDER` | `gemini`（默认）或 `openai-compatible` |
| `YTRIPLE_MODEL` | 默认 `gemini-3.8-flash`；兼容提供方须设置其实际模型名 |
| `OPENAI_API_KEY` / `OPENAI_BASE_URL` | 兼容提供方凭据与包含 `/v1` 等前缀的 API 基础地址 |

模型配置变化需要重启服务。服务监听、数据存储和访问令牌由服务拥有者管理。公网连接使用 HTTPS。P1 服务面向一个拥有者的私有工作空间，多设备共用这一空间；完整账号、付费订阅及多用户托管尚未实现。

## 桌面使用

在另一终端运行：

```sh
npm run dev
```

在设置中连接服务地址和访问令牌。也可以选择本机独立模式，并配置本地模型。macOS 本地凭据与服务令牌使用系统安全存储加密，界面不会读回已保存密钥。P1 桌面数据使用独立的 `~/Library/Application Support/ytriple-p1/`，保留已有旧版 ytriple 数据原状。

1. 输入目标，选择“开始协作”，团队直接开始处理。需要补充资料时选择“先准备材料”，添加文本或导入 Markdown、TXT、JSON、CSV 后开始，目标不必重输。
2. 在“交流”“协作过程”“成果”中查看统筹分工、成员公开分析、核查与成果汇合；也可直接向成员提问。
3. 引用某个步骤追问或提出修正，引用成果版本／片段要求修改。手工编辑保存为新版本，版本冲突保留为待合并草案；成果可查看本版对应的处理过程与输入依据。
4. 查看过程总结或工作复盘，继续同一项工作。关闭后重开保留工作、记录、版本和已保存草稿。

宽屏可同时对照三个窗口，窄屏通过标签切换。过程是成员面向用户的公开分析和方法说明。停止只保证应用停止本轮处理，远端提供方可能已经产生用量；服务异常重启后，未确认运行会标为中断，需核对已有内容再继续。

## 多端准备

当前先完善桌面端，手机 App 在后续阶段开发。服务接口已与桌面界面分离，后续手机可继续同一项服务工作。

切换本地模式或服务器地址会进入独立空间，当前没有自动迁移和离线双向同步。桌面保留交流草稿、阅读位置与布局。

## 构建与验证

```sh
npm run check          # 类型、模块边界、回归测试、桌面构建
npm run test:ui        # Electron 实际操作，使用隔离模型替身
npm run server:build   # dist/server/index.mjs
npm run package        # Apple Silicon macOS .app，release/ 内
```

已配置模型且明确接受少量真实调用时，可执行 `YTRIPLE_LIVE_TEST=1 npm run test:live`；仅使用脚本内虚构材料，生成独立临时工作空间并清理。OpenAI 兼容传输有本机协议检查，用户实际提供方须另行验证。

提供了服务容器构建文件；数据目录挂载至 `/data`，凭据通过部署环境注入。当前 macOS 产物未签名、公证；手机商店发布包、正式服务器部署和跨平台发行尚未交付。

项目初始化与 Codex 交接、既有项目理解与建议回写、雷达来源和订阅、长期自动化及学习进化，仍在后续开发范围。已有入口明确显示状态。
