# yTriple

Three Agents, One Perfect Output.

yTriple 是一款轻量、垂直的桌面端独立效率工具。它通过一个主 Agent 与两个专业副 Agent 的并行协作，把复杂任务转成一套可视化的“头脑风暴 -> 反向审计 -> 最终综合”闭环，输出更稳健、更高质量的结果。
